# Roadmap

## Frozen scope

- Base runtime: NousResearch Hermes Agent.
- Project scale: Full.
- RSI: controlled Harness-only optimization.
- Product: Personal Super Agent with long-running tasks, memory, Skills, tools, and multi-agent coordination.

## Phases

0. Upstream provenance, baseline validation, repository bootstrap.
1. Personal Agent control plane: task identity, state, API, Hermes adapter.
2. Memory and context: user profile, episodic/semantic/procedural memory, consolidation.
3. Harness and Skills governance: immutable specs, registry, versioning, MCP integrations.
4. Multi-agent orchestration: supervisor, delegation contracts, independent review, A2A adapter.
5. Always-on execution: scheduling, event triggers, resumability, browser automation.
6. Controlled RSI: trace collection, diagnosis, proposals, isolated probes, composition, promotion/rollback.
7. Security and evaluation: sandbox integration, approvals, adversarial tests, tracing, regression gates.
8. Product delivery: web workspace, deployment, documentation, benchmarks, release.

## Non-goals for the initial release

- Autonomous modification of source code or model weights.
- Unbounded autonomous operation.
- Unreviewed permission expansion.
- Reimplementing Hermes' native agent loop, tool registry, or memory provider system.
- Adding frameworks solely to increase the technology count.
